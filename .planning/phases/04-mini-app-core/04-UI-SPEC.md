## Color & Theme Integration

Strict adherence to Telegram Mini App SDK (`@twa-dev/sdk`) variables:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--tg-theme-bg-color)` | App background, sheet backgrounds |
| Secondary (30%) | `var(--tg-theme-secondary-bg-color)` | Cards, drawer surfaces, input fields |
| Accent (10%) | `var(--tg-theme-button-color)` | Primary CTA, active tab indicators |
| Destructive | `var(--tg-theme-destructive-text-color)` | Delete buttons, error text |
| Text | `var(--tg-theme-text-color)` | Primary body and heading text |
| Hint Text | `var(--tg-theme-hint-color)` | Timestamps, empty state copy, labels |

Accent reserved for: Primary action buttons (Categorize, Save), active state indicators, and floating action buttons. Never use for standard text or generic borders.

### Category Icon & Color System
Categories use predefined Tailwind hex codes stored in the Sheet data:
- Parent & Child categories inherit assigned colors.
- Icons map to `lucide-react` components based on string keys.
- Category pills in UI display a `16px` icon and background at 15% opacity of the assigned hex color, text at 100% opacity of the hex color.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Inbox List | ✅ covered | Empty results render the documented 'Inbox Zero' copy |
| loading | Transaction Feed | ✅ covered | Displays Shadcn Skeleton elements matching transaction row height |
| error | Data Fetching | ✅ covered | Error state renders documented copy and a retry button |
| long-text | Merchant Name | ✅ covered | Truncates to 1 line with ellipsis (`truncate` class) |

### Drawer Interactions (Shadcn Bottom Sheet)
- **Trigger**: Tapping an uncategorized transaction in the Inbox.
- **Behavior**: Drawer slides up holding category hierarchy. Must include `overscroll-behavior: contain` to prevent Telegram's native swipe-to-close behavior from closing the entire Mini App accidentally. 
- **UX Flow**: Displays parent categories in a grid. Tapping a parent reveals its children. Selecting a child automatically triggers the categorize mutation and closes the Drawer.
