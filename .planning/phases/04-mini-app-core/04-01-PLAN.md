# Phase 4 Plan: Wave 1 - Foundation & Inbox

## Goal
Set up React Router, Zustand store, React Query, Telegram SDK initialization, and the basic layout with the Inbox view for uncategorized transactions.

## must_haves
- Application initializes Telegram SDK and respects theme colors.
- Routing is configured for `/` (Inbox) and `/categories` (Categories).
- Zustand store holds `initData` and `theme`.
- React Query fetches transactions via API and displays them in Inbox.

## Tasks

### 1. Configure Global Store and API Client
```xml
<task>
<read_first>
- frontend/package.json
- worker/src/index.ts
</read_first>
<action>
Create `frontend/src/store/index.ts` using Zustand to store:
- `initData: string | null`
- `theme: 'light' | 'dark'`
Create `frontend/src/lib/api.ts` with a `fetcher` function that includes `x-telegram-init-data` from the Zustand store.
Setup TanStack React Query `QueryClientProvider` in `frontend/src/main.tsx`.
</action>
<acceptance_criteria>
- File `frontend/src/store/index.ts` exists and exports `useAppStore`.
- File `frontend/src/lib/api.ts` exists and handles POST to `VITE_API_URL` with auth headers.
- `main.tsx` wraps App with `QueryClientProvider`.
</acceptance_criteria>
</task>
```

### 2. Implement Telegram SDK Initialization
```xml
<task>
<read_first>
- frontend/src/App.tsx
</read_first>
<action>
Update `frontend/src/App.tsx` to:
- Import `WebApp` from `@twa-dev/sdk`.
- Call `WebApp.ready()`.
- Sync `WebApp.initData` to Zustand store.
- Apply `WebApp.colorScheme` to HTML `class="dark"` via useEffect.
- Configure `react-router-dom` `RouterProvider` for layout.
</action>
<acceptance_criteria>
- App initializes and sets dark mode based on Telegram theme.
</acceptance_criteria>
</task>
```

### 3. Build Inbox View (Uncategorized Transactions)
```xml
<task>
<read_first>
- frontend/src/App.tsx
</read_first>
<action>
Create `frontend/src/pages/Inbox.tsx`:
- Use `useQuery` to fetch `action: get_transactions`.
- Filter transactions where `category_id` is null or empty.
- Render a list of transactions using Tailwind/Shadcn styling.
- Create `frontend/src/components/Layout.tsx` for bottom navigation (Inbox vs Categories).
</action>
<acceptance_criteria>
- `Inbox.tsx` renders loading state, then list of transactions.
- Bottom navigation allows switching between pages.
</acceptance_criteria>
</task>
```
