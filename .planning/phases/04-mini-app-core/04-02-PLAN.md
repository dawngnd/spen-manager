# Phase 4 Plan: Wave 2 - Categories & Actions

## Goal
Implement Category Management (CRUD), the Category Picker Drawer, and Transaction Categorization mutation.

## must_haves
- Categories page lists parent/child categories.
- User can create, edit, delete categories via API.
- Clicking an uncategorized transaction opens Shadcn Drawer.
- Drawer allows selecting a category to dispatch `categorize_transaction` action.
- UI handles loading and optimistic updates during categorizing.

## Tasks

### 1. Build Category Management API Hooks
```xml
<task>
<read_first>
- frontend/src/lib/api.ts
</read_first>
<action>
Create `frontend/src/hooks/useCategories.ts` using React Query.
- `useGetCategories`: queries `action: get_categories`.
- `useUpsertCategory`: mutates `action: upsert_category` and invalidates query.
- `useDeleteCategory`: mutates `action: delete_category` and invalidates query.
</action>
<acceptance_criteria>
- Hooks are exported and successfully invalidate cache on success.
</acceptance_criteria>
</task>
```

### 2. Implement Category Page UI
```xml
<task>
<read_first>
- frontend/src/pages/Inbox.tsx
</read_first>
<action>
Create `frontend/src/pages/Categories.tsx`.
- Fetch categories using `useGetCategories`.
- Render a list of categories grouped by Parent -> Child.
- Add "Create Category" button opening a Dialog with a form (Name, Icon, Color).
- Add Edit/Delete buttons per category.
</action>
<acceptance_criteria>
- Page renders grouped categories.
- Form submits payload to `useUpsertCategory`.
</acceptance_criteria>
</task>
```

### 3. Implement Categorization Drawer
```xml
<task>
<read_first>
- frontend/src/pages/Inbox.tsx
</read_first>
<action>
Create `frontend/src/components/CategorizeDrawer.tsx`.
- Accept `transactionId` as prop.
- Fetch categories inside Drawer.
- Render category list (click to select).
- Use a new hook `useCategorizeTransaction` (mutates `action: categorize_transaction`) on selection.
- Invalidate `get_transactions` query upon success.
- Integrate Drawer into `Inbox.tsx` (open on clicking a transaction).
</action>
<acceptance_criteria>
- Clicking a transaction opens Drawer.
- Selecting a category fires API call.
- Drawer closes and transaction disappears from Inbox upon success.
</acceptance_criteria>
</task>
```
