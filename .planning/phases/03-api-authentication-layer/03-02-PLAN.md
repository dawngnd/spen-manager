    Extend doPost() in src/API.ts with 3 category action handlers.

    1. get_categories: Read Categories sheet (schema from src/Setup.ts — 5 cols: id, name, parent_id, icon, color). Return all rows as array of objects { id, name, parent_id, icon, color }. Return { success: true, data: [...] }.

    2. upsert_category: Expect payload { id?, name, parent_id, icon, color }. Wrap in withLock("categories"). If id provided, find row by id column match, overwrite values. If no id or not found, appendRow with generated id. Return { success: true, data: { id } }.

    Access Categories sheet via SpreadsheetApp.getActiveSpreadsheet().getSheetByName() using the tab name from src/Setup.ts. Use getDataRange().getValues() for reads, sheet.deleteRow() for deletes.
