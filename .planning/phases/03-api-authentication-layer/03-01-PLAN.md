    1. Create worker/package.json with devDependencies: @cloudflare/workers-types, typescript, wrangler.
    2. Create worker/tsconfig.json targeting ES2022 modules with @cloudflare/workers-types in types.
    3. Create worker/wrangler.toml with name "spen-manager-api", main "src/index.ts", compatibility_date "2024-01-01", [vars] GAS_WEB_APP_URL placeholder, and [env.production] bindings for TELEGRAM_BOT_TOKEN (secret).
    4. Create worker/src/index.ts with:
       - CORS preflight handler for OPTIONS requests returning Access-Control-Allow-Origin: *, Access-Control-Allow-Headers: Content-Type, x-telegram-init-data.
       - Read x-telegram-init-data header from POST requests.
       - Port verifyTelegramWebAppData from src/Utils.ts to Web Crypto API: HMAC-SHA256 using crypto.subtle.importKey and crypto.subtle.sign. Use TextEncoder for string-to-buffer. Parse initData as URLSearchParams, extract data-check-string per Telegram spec (sorted key=value pairs excluding hash), compute HMAC with WebAppData-derived secret key, compare hex with hash param.
       - On auth failure: return 401 JSON { success: false, error: "Unauthorized" } per D-05.
       - On auth success: proxy request body to env.GAS_WEB_APP_URL via fetch(), return GAS response. If GAS returns non-JSON (HTML redirect), return 502 JSON { success: false, error: "Backend unavailable" }.
       - Export default { fetch: handler } as ES module worker format.
  </action>
